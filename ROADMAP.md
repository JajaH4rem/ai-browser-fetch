# Roadmap

## Phase 1 — Core MVP ✅
Reliable browser-backed fetch with plain text output, retry logic, and exit codes.

`--wait`, `--wait-for`, `--wait-until`, `--selector`, `--max-chars`, `--timeout`, `--retry`

## Phase 2 — AI-Friendly Output ✅
Structured output modes for LLM consumption.

`--json`, `--markdown` (Readability), `--url`

## Phase 3 — Reliability & Compatibility
Handle more real-world sites and edge cases.

`--stealth` (playwright-extra), `--ua`, `--headed`, `--screenshot`

## Phase 4 — Advanced Features
Power-user features and ecosystem polish.

`--links`, `--metadata`, cookies/auth, global `ai-fetch` binary

---

If you want to work on something in Phase 3 or 4, open an issue first to discuss it.
